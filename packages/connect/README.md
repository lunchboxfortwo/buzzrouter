# @buzzrouter/connect

Runs the one-shot BuzzRouter connector setup command generated by a verified
community owner's dashboard.

```text
npx --yes @buzzrouter/connect@0.1.0 <one-time-token>
```

Run it on the Buzz relay host. The installer:

1. resolves the relay and dedicated bridge public key from BuzzRouter;
2. runs `./run.sh add-member` when Buzz's production helper is present,
   otherwise runs `buzz-admin add-member`;
3. asks BuzzRouter to authenticate the encrypted bridge key, publish a signed
   profile, query it back, and consume the token.

Relay credentials and database access remain on the relay host. The installer
only sends the one-time token to BuzzRouter.

For a nonstandard deployment, set a structured command prefix:

```text
BUZZROUTER_ADMIN_COMMAND='["docker","compose","exec","-T","relay","buzz-admin"]'
```

The command is parsed as a JSON array and executed without a shell.
